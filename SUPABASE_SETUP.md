# Supabase Setup Guide

## 1. Get API Keys
1.  Go to your [Supabase Dashboard](https://supabase.com/dashboard).
2.  Click on your project.
3.  In the left sidebar, go to **Settings** (Gear icon) -> **API**.
4.  Copy the **Project URL** and paste it into `.env.local` as `NEXT_PUBLIC_SUPABASE_URL`.
5.  Copy the **anon public** key and paste it into `.env.local` as `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

## 2. Create Database Table
1.  In the left sidebar, click on **SQL Editor**.
2.  Click **New Query**.
3.  Paste and run the following code:

```sql
-- Create the vehicles table
create table vehicles (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  price text not null,
  category text not null,
  description text,
  image text not null
);

-- Turn on security
alter table vehicles enable row level security;

-- Allow everyone to read vehicles (public)
create policy "Vehicles are public"
  on vehicles for select
  to public
  using (true);

-- Allow everyone to insert/delete (since we have hardcoded admin login for now)
-- Ideally you'd use Supabase Auth, but this keeps it simple as requested
create policy "Enable insert for all"
  on vehicles for insert
  to public
  with check (true);

create policy "Enable delete for all"
  on vehicles for delete
  to public
  using (true);
```

## 3. Create Storage Bucket
1.  In the left sidebar, click on **Storage**.
2.  Click **New Bucket**.
3.  Name it: `vehicle-images`.
4.  **Important**: Switch "Public bucket" to **ON**.
5.  Click **Save**.
